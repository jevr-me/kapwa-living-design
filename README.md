# Kapwa Living Design

**An open, Filipino-rooted framework for designing living systems.**

Designing Forward From Our Own Roots

Foundational version 1.0 · November 2026  
John Eric V. Roxas (Eric Roxas) · Siquijor, Philippines

KLD begins with Kapwa: we are part of each other. It is a way of understanding our place within the world and consciously designing how we live within it. It works alongside permaculture and systems thinking, rather than replacing them.

## The framework

- **KAPWA** — We are part of each other.
- **LOOB ↔ LABAS** — We shape our world; the world we create shapes us.
- **READ AND DESIGN THE SYSTEM** — Yaman, Ugnay, Daloy, Bunga, Bigat.
- **ISABUHAY** — Bring it to life, learn from what happens, and keep shaping it.

Read and design again through the same five lenses.

## Open development

Use, teach, translate, critique, adapt and build upon the framework. Independent forks are welcome; contributions back to the official framework are voluntary. This is a foundational framework, not a validated technical standard.
